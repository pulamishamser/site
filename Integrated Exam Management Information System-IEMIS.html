Use & Features of Integrated Exam Management Information System-IEMIS

Opened for all school

Features.

  •  adopted prescribed guideline & policy by CEHRD(letter grading system and curriculum framework )
  •  Online mark entry can be done, and reports can be obtained within 5 minutes
  •  Both single and multi-grade sheet ledgers and admission cards can be accessed
  •  Result sheets can be printed and pasted on the notice wall
  •  tudents can also download grade sheets online.
  •  It is easy to maintain records of any year's quarterly or annual examinations.
  •  Security by user ID and passwords
  •   Any school can use prepare results

Key points to use while using IEMIS software...

  •  Type : shamser.info.np
  •  Go to 3 dots (...) for mobile user
  •  Choose IEMIS
  •  Go to 3 dots or given link
  •  Open search browser
  •  Go to 3 dots (...) for mobile user
  •  Choose IEMIS
  •  Go to 3 dots or given link
  •  Login Data Entry form
  •  Data can be entered without marks
  •  Complete data entry work
  •  Refresh pressing refresh button after data entry and update
  •  Look up menu bar (...)
  •  Choose what you want
  •  srudents are provided copy link to find result
  •  For internal results ,clear the Credit Hour and FM fields.
  •  You can also enter the marks based on the FM in which the exam was conducted.
